# Mega Transportation - Complete Color Palette

## Overview
This document contains all colors used in the Mega Transportation project. Each color is provided in multiple formats (OKLch, HEX, RGB) for easy conversion to Flutter.

---

## Color Conversion Guide

### OKLch to HEX Conversion
- **OKLch Format**: `oklch(L C H)` where:
  - **L** (Lightness): 0-1 (0=black, 1=white)
  - **C** (Chroma): 0-0.4 (saturation level)
  - **H** (Hue): 0-360 (color angle)

- **Near White** (Background): `#F8F8F8` - Reduces eye strain
- **Pure White** (Card): `#FFFFFF` - Elevated surfaces
- **Dark Gray** (Foreground): `#262626` - Primary text

### Dark Mode Palette
- **Bright Cyan** (Primary Dark): `#00D9FF` - High contrast for dark backgrounds
- **Dark Navy** (Background Dark): `#1F1F1F` - Dark surfaces

- **Red** (Destructive): `#DC2626` - Errors, deletions, warnings

## Tips for Flutter Implementation

1. **Color Constants**: Define all colors as static constants in a dedicated `colors.dart` file
2. **Theme Extension**: Use Flutter's `ThemeExtension` to add custom colors to the theme system
3. **Accessibility**: Ensure contrast ratios meet WCAG AA standards (minimum 4.5:1 for text)
4. **Dark Mode Support**: Always provide both light and dark theme colors
5. **Dynamic Colors**: Use `MediaQuery` to switch between themes based on system preference
6. **State Colors**: Use opacity/tints of primary colors for hover, active, and disabled states
